Line-Scan Hyperspectral 3D Gaussian Splatting

A homebuilt pushbroom spectrograph rides a robot arm, and the 3D Gaussian splat it trains stores a full 500–950 nm spectrum in every Gaussian instead of an RGB color.

Open the viewer Source on GitHub

How it works

  1. 1 · Pick a viewpoint

    The SO-101 arm carries the scanner head to a pose and holds still. An RGB camera on the head reads an AprilTag board to get that pose.

  2. 2 · Sweep the slit

    A NEMA 8 stepper turns the scan mirror one microstep per frame. Each frame is one line of the object by its spectrum.

  3. 3 · Train the splat

    Every scan line is a training sample. A C++/CUDA renderer draws the splat through a line-camera model at that line's pose and compares it with the measured line.

In the browser

The viewer opens a splat trained from 16 synthetic sweeps. Show it at any single wavelength, in true color, in color infrared or as a band index such as NDVI, and click anywhere to plot the full spectrum there. It is plain HTML, JavaScript and WebGL2.
